GWBMEditor – exemplos avançados

Serve esta pasta por HTTP (Apache) para que o exemplo 2 (upload.php) funcione.

1) Botões personalizados: ação simples, menu e painel

Três botões criados com a opção buttons e usados pelo nome na barra.

2) Upload de imagem para o servidor (uploadUrl) + colar/arrastar imagens

Use o botão de imagem (campo “Enviar arquivo”), cole uma imagem da área de transferência ou arraste um arquivo para o editor.

3) Documento HTML completo (fullPage)

O <!DOCTYPE>, o <head> e os atributos de <html>/<body> são preservados; os <style> do head são aplicados na edição.
